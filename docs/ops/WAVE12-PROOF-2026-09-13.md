# Wave 12 proof — GSC sitemap submit/delete (Consent S)

Date: 2026-09-13  
Branch: `cursor/wave12-gsc-sitemaps-9af1`  
Base: `6d1adaf` (Wave 11 GA4 Admin writes + Ads-id recipes)  
Goal: Submit and delete sitemaps without the Search Console UI. Writes use Consent S (`webmasters`). Reads stay Consent A (`webmasters.readonly`).

## What shipped

| Item | Detail |
| --- | --- |
| HTTP | `GoogleGscWriteHttp` — searchconsole.googleapis.com only; PUT/DELETE sitemaps.submit / sitemaps.delete |
| Consent A lock | `GoogleHttp` refuses sitemap mutate / Indexing paths; GET + searchanalytics.query + urlInspection.inspect stay |
| Writes on S | `gsc_submit_sitemap` (PUT), `gsc_delete_sitemap` (DELETE) |
| Params | Exact `site_url` + `feedpath`. No silent slash / `sc-domain:` coercion |
| Confirm | Live mutate `confirm` / `confirm_phrase` must include that `site_url` |
| Flag | `DGTL_WRITES_ENABLED` still gates live mutates; login does not flip it |
| Store | Consent S = `google-oauth-gsc-write.json` (Wave 10) |

Named tools only. No Indexing API / `gsc_request_indexing`. No `gsc_add_site` / `gsc_delete_site` (Wave 13+). Never Axos.

## Locks held

- Consent A never receives write scopes. S store = `google-oauth-gsc-write.json`.
- Write tools **not** in `CONSENT_A_TOOLS` (family `gsc_write`). Kernel stays **24**.
- `A ∩ S = ∅` (`tests/consent-gs.test.ts`, `tests/gsc-write.test.ts`).
- Wrong `site_url` (confirm mismatch or Google 404) is a clear `INVALID_ARGUMENT` / `NOT_FOUND` with `gsc_list_sites` hint.
