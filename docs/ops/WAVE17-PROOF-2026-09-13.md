### Stamp builder notes (Worker, not this repo)

- `tiktok_list_catalogs`: GET `catalog/get/` with `advertiser_id` + optional `bc_id` / `catalog_id`. ads_read.
- `tiktok_create_catalog`: POST `{bc_id?, name/catalog_name, catalog_type, currency?}`. Gate on `TIKTOK_MUTATE_ENABLED`.
- `tiktok_upload_catalog_products`: map `params.products[]` → Catalog JSON (`sku_id`, `title`, `availability`, `price_info.{price,currency,sale_price}`, `image_url`, `landing_page.landing_page_url`, optional `product_detail`). Gate on `TIKTOK_MUTATE_ENABLED`. HTTPS only.
- `tiktok_bind_catalog_eventsource`: POST `{advertiser_id, bc_id?, catalog_id, pixel_code|app_id}`. Gate on `TIKTOK_MUTATE_ENABLED`.
- `tiktok_list_pixels`: GET `pixel/list/` with `advertiser_id`. ads_read.
- `tiktok_track_events`: map `params.events[]` → Events API 2.0 `data[]` (`event` from `event_name`, `event_time`, `event_id`, `page.url` from `event_source_url`, hashed `user.email`/`user.phone`, `properties.content_id` / `contents[]`, `properties.value`). Top-level `event_source` + `event_source_id` from `pixel_code`. `test_event_code` optional. Gate on **`TIKTOK_EVENTS_ENABLED`** (not `TIKTOK_MUTATE_ENABLED`). Health must expose `tiktok_events_enabled`. Never log unhashed PII (plugin already hashes). `content_id` must match catalog `sku_id`.
- `tiktok_create_campaign`: POST `{advertiser_id, campaign_name, objective_type, budget_mode, budget?, operation_status}`. Default `DISABLE`. Gate on `TIKTOK_MUTATE_ENABLED`.
- Closed HTTPS fields added: `image_url`, `landing_page_url`.
