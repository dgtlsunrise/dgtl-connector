## Locks held

- Default install stays `read_products` + `read_orders` + `read_inventory` + `read_locations`.
- **Explicit expand** (reinstall; never silent on an existing app): `read_publications`, `read_product_listings`, `write_inventory`, `write_products`.
- Missing detectable scope → `SHOPIFY_SCOPE_MISSING` (zero HTTP).
- Catalogs list uses existing `read_products` (not Meta). Publications need `read_publications`. Feeds need `read_product_listings`. `productSet` needs `write_products`.
- `productSet` variants/tags **replace** omitted list entries (dry_run warning).
- Kernel stays **26**. Shopify stays LOCAL_FREE.
